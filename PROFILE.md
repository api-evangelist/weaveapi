# WeaveAPI - OpenAI-compatible AI API Gateway

WeaveAPI is an OpenAI-compatible /v1 gateway for calling supported model families (OpenAI, Anthropic, DeepSeek, Qwen, Kimi, GLM, MiniMax) through a clean OpenAI-compatible API. Keep your SDK, change the base URL, and manage keys, balance, usage, and top-ups in a hosted console. Prepaid pay-as-you-go pricing with a $1 signup credit.

- **Provider:** https://weaveapi.dev/
- **Documentation:** https://weaveapi.dev/docs/
- **Base URL:** https://api.weaveapi.dev/v1
- **Tags:** AI, LLM, AI inference, API gateway, aggregator, OpenAI-compatible, developer tools, model routing

## APIs

- **WeaveAPI OpenAI-compatible API** — OpenAI-wire-compatible REST API for chat completions, responses, and model catalog. Authenticated with a bearer API key. Also offers an Anthropic/Claude-compatible Messages route on the api.weaveapi.dev host without /v1. (`https://api.weaveapi.dev/v1`)
